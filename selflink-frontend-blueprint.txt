SELF­LINK — FRONTEND DESIGN & IMPLEMENTATION BLUEPRINT (v1)
Date: 2025-10-29


================================================================================
PURPOSE
--------------------------------------------------------------------------------
This document defines the **frontend vision and design system** for SelfLink.
It provides clear direction on:
- Visual identity (colors, typography, animations, atmosphere)
- User interface patterns and interactivity
- Communication with backend (API, real-time updates, caching)
- Component architecture (React/Vanilla/HTML-first MVP option)
- Accessibility and performance goals

The goal is a **calm, elegant, emotionally warm** interface that builds
trust, focus, and curiosity rather than addiction or overstimulation.


================================================================================
1) DESIGN PHILOSOPHY
--------------------------------------------------------------------------------
SelfLink’s frontend should feel like a digital temple — serene, subtle,
intelligent, alive. Each element supports awareness, reflection, and connection.

🧘‍♂️ Principles:
• Calm before clever — elegance > complexity
• Minimal but emotionally resonant
• Every color and motion conveys serenity and depth
• Natural light gradients — no harsh contrasts
• Micro-animations that feel alive, not flashy
• Typography that breathes
• Harmony between UI and AI mentor tone

🪷 Keywords:
serenity · trust · cosmic · connection · introspection · flow


================================================================================
2) COLOR SYSTEM (PRIMARY PALETTE)
--------------------------------------------------------------------------------
The palette must evoke safety, intelligence, and higher awareness.

🌈 Core colors:
• Deep Space Blue        #0B0E26 — background foundation (calm, cosmic depth)
• Celestial Teal         #00C6A7 — trust, vitality, connection
• Soft Lavender          #B29BFF — inspiration, imagination
• Misty White            #E8F1F5 — clarity, breath
• Aurora Gradient         → linear-gradient(90deg, #74b9ff, #a29bfe, #81ecec)

🌅 Secondary (accents):
• Rose Quartz (#FADADD) — empathy, love
• Golden Sunbeam (#FFD36E) — positive energy, hope
• Indigo Veil (#3D3D6B) — mystery, depth

All gradients use soft transitions with low contrast and slight transparency.
Use blur (5–20px) for floating cards to simulate glass-like serenity.


================================================================================
3) TYPOGRAPHY
--------------------------------------------------------------------------------
Fonts:
• Headings: Poppins or Inter (weight 600–700)
• Body: Open Sans or Lato (weight 400–500)
• Quote/AI text: “DM Sans” or “Raleway” for warmth

Sizes:
• h1: 2.8rem — gradient text, subtle float animation
• h2: 2rem — solid or semi-transparent
• body: 1.1rem — maximum readability (60–80 chars per line)
• small: 0.9rem — dimmed gray-blue (#9AA5B1)

Letter spacing: 0.03em  
Line height: 1.6–1.8  
Text alignment: left with max 800px width for focused reading.


================================================================================

Containers: 90% width, max 1440px, auto-centered.

UI Architecture:
• Global: Header, Sidebar (or floating menu), Footer

================================================================================
5) BACKGROUND & ANIMATIONS
--------------------------------------------------------------------------------
🎇 MatrixBackground (Canvas/JS)
• Floating dots + lines connecting softly (network of souls)
• Gentle parallax movement (mouse/scroll-reactive)
• Gradient overlays fading with opacity 0.2–0.4
• Starfield-like particles with variable blur

✨ Page Transitions
• Fade + upward motion (0.6s ease-in-out)
• Shared element transitions (logo, header text)

🎞️ Micro-interactions
• Button hover → glow + gradient shift
• Card appear → soft scale-in (0.96 → 1.00)
• Input focus → gradient underline glow
• Modal open → fade + float-in

🌊 Ambient animation loop
• Light aurora effect behind main content
• Slight camera drift illusion (depth)
• Maintain 60fps — smooth, never aggressive

================================================================================
8) FRONTEND–BACKEND INTERACTION
--------------------------------------------------------------------------------
API:
• Axios/Fetch client with token refresh (JWT)
• Endpoints: /api/v1/* (users, posts, messages, mentor, matrix, payments)

State:
• Redux Toolkit or Zustand for light state mgmt
• React Query (TanStack) for API caching and revalidation

Auth Flow:
• Register → Save local JWT → Redirect to dashboard
• Refresh tokens auto-renew before expiry
• Handle 401 errors → logout + redirect gracefully

Real-time:
• WebSocket client for DMs + Mentor live typing
• Reconnect logic + exponential backoff
• Heartbeat ping every 25s

Caching:
• API layer caches with localStorage/sessionStorage
• IndexedDB for offline posts/messages sync

Performance:
• Lazy load routes
• Code splitting per page
• Preload hero visuals + MatrixBackground async
• Lighthouse target: >90 on all metrics


================================================================================
9) RESPONSIVENESS & ACCESSIBILITY
--------------------------------------------------------------------------------
• Mobile-first layout (breakpoints: 480, 768, 1024, 1440)
• Keyboard navigation, focus rings, ARIA labels
• High-contrast mode (optional)
• Reduced motion toggle for accessibility
